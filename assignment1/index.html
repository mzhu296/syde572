Problem

We want to find the shortest Euclidean distance between several given points and the parabola

\[ y = x^2 + 5. \]

The five points are

\[ (0,0),\quad (-4,0),\quad (-8,0),\quad (2,0),\quad (6,0). \]

General Analytical Approach

Step 1: Choose an arbitrary point on the parabola

Any point on the parabola \(y=x^2+5\) can be written as

\[ Q = (x,\;x^2+5). \]

Let the given point be

\[ P=(a,0). \]

Step 2: Write the distance equation

The Euclidean distance between \(P\) and \(Q\) is

\[ d(x) = \sqrt{(x-a)^2+(x^2+5)^2}. \]

Instead of minimizing \(d(x)\), we minimize the squared distance

\[ D(x) = (x-a)^2+(x^2+5)^2. \]

Since the square-root function is monotonically increasing, the value of \(x\) that minimizes \(D(x)\) also minimizes \(d(x)\).

Step 3: Differentiate

\[ D'(x) = 2(x-a) + 2(x^2+5)(2x). \]

Simplifying,

\[ D'(x) = 2(x-a)+4x(x^2+5). \]
\[ D'(x) = 4x^3+22x-2a. \]

Step 4: Set the derivative equal to zero

\[ 4x^3+22x-2a=0. \]

Dividing by 2 gives the general equation

\[ \boxed{2x^3+11x-a=0}. \]

We solve this equation for each of the five given points.

1. Point \(P=(0,0)\)

Step 1: Squared distance

\[ D(x) = (x-0)^2+(x^2+5)^2. \]
\[ D(x) = x^2+x^4+10x^2+25. \]
\[ D(x) = x^4+11x^2+25. \]

Step 2: Differentiate

\[ D'(x) = 4x^3+22x. \]

Step 3: Set \(D'(x)=0\)

\[ 4x^3+22x=0. \]
\[ 2x(2x^2+11)=0. \]

The only real solution is

\[ x=0. \]

Step 4: Find the corresponding point

\[ y=0^2+5=5. \]

Therefore the closest point on the parabola is

\[ Q=(0,5). \]

Step 5: Find the minimum distance

\[ d = \sqrt{(0-0)^2+(5-0)^2} = 5. \]
Result:
Closest point: \( (0,5) \)
Minimum distance: \[ \boxed{d=5} \]

Numerical Method Visualizations

Both numerical methods minimize the squared distance rather than the distance itself. This avoids differentiating a square root and preserves the location of the minimum:

\[ D(x)=(x-x_0)^2+[f(x)-y_0]^2. \]

Newton-Raphson method

Differentiating the squared-distance objective gives

\[ D'(x)=2(x-x_0)+2[f(x)-y_0]f'(x), \] \[ D''(x)=2+2[f'(x)]^2+2[f(x)-y_0]f''(x). \]

The stationary point is found with the Newton update

\[ \boxed{x_{k+1}=x_k-\frac{D'(x_k)}{D''(x_k)}}. \]

For \(f(x)=x^2+5\), \(f'(x)=2x\) and \(f''(x)=2\). Because all five supplied points have \(y_0=0\), the derivatives simplify to

\[ D'(x)=4x^3+22x-2x_0, \qquad D''(x)=12x^2+22. \]

The implementation uses \(x_0^{\text{guess}}=0\), stops when \(|x_{k+1}-x_k|<10^{-7}\), and permits at most 100 iterations. It also stops safely if \(|D''(x_k)|<10^{-12}\). Since \(D''(x)=12x^2+22>0\), the parabola example has one global minimum.

Golden-section search

Golden-section search does not require derivatives. It begins with a bounded interval \([a,b]\) containing a unimodal minimum and evaluates two interior points using \(\phi=(1+\sqrt5)/2\) and \(r=2-\phi\approx0.381966\):

\[ x_1=a+r(b-a), \qquad x_2=b-r(b-a). \]

If \(D(x_1)<D(x_2)\), the right portion cannot contain the minimum and the new interval becomes \([a,x_2]\). Otherwise, the left portion is discarded and the new interval becomes \([x_1,b]\). One previous function evaluation is reused after every reduction.

For the parabola, the code starts with \([a,b]=[-10,10]\), stops when \(|b-a|<10^{-7}\), and allows at most 1000 iterations. The final estimate is the midpoint \((a+b)/2\).

Verification That These Are Minima

The second derivative of the general squared-distance function is

\[ D''(x) = 12x^2+22. \]

Since

\[ 12x^2+22 > 0 \]

for every real value of \(x\), the squared-distance function is strictly convex. Therefore, each critical point found above is the unique global minimum for its corresponding given point.

SYDE 572 · Assignment 1 · Part Two

Least-squares function fitting

Analytical and numerical fitting of a straight line and parabola by minimizing squared error.

Handwritten Part Two Solution

The handwritten matrix calculations for the line and parabola fits are embedded below. Open or download part2.pdf.

1. Given Data and Objective

The data points are

\[ (0,0.5),\quad (1,1.5),\quad (2,3.5),\quad (3,7.5). \]

For a fitted model \(\hat y(x)\), define the error at each point as

\[ e_i=\hat y(x_i)-y_i. \]

We minimize the sum of squared errors (SSE)

\[ \rho=\sum_{i=1}^{4}e_i^2. \]

The mean squared error is

\[ \mathrm{MSE}=\frac{\rho}{4}. \]
Minimizing SSE and minimizing MSE give exactly the same fitted parameters because MSE is only SSE multiplied by the constant \(1/4\).

2. Fit a Straight Line

Use the line model

\[ \hat y(x)=c_0+c_1x, \]

where \(c_0\) is the intercept and \(c_1\) is the slope.

2.1 Write the four errors

\[ \begin{aligned} e_1 &= c_0-0.5,\\ e_2 &= c_0+c_1-1.5,\\ e_3 &= c_0+2c_1-3.5,\\ e_4 &= c_0+3c_1-7.5. \end{aligned} \]

2.2 Build the least-squares loss

\[ \rho(c_0,c_1)= (c_0-0.5)^2+ (c_0+c_1-1.5)^2+ (c_0+2c_1-3.5)^2+ (c_0+3c_1-7.5)^2. \]

Expanding and collecting like terms gives

\[ \boxed{ \rho(c_0,c_1)= 4c_0^2+12c_0c_1+14c_1^2-26c_0-62c_1+71 } \]

2.3 Differentiate with respect to both parameters

\[ \frac{\partial \rho}{\partial c_0}=8c_0+12c_1-26 \] \[ \frac{\partial \rho}{\partial c_1}=12c_0+28c_1-62. \]

At the minimum, set both partial derivatives equal to zero:

\[ 8c_0+12c_1-26=0 \] \[ 12c_0+28c_1-62=0. \]

Divide both equations by 2:

\[ \boxed{4c_0+6c_1=13} \] \[ \boxed{6c_0+14c_1=31}. \]

2.4 Solve for \(c_0\) and \(c_1\)

Multiply the first equation by 3 and the second by 2:

\[ 12c_0+18c_1=39 \] \[ 12c_0+28c_1=62. \]

Subtract:

\[ 10c_1=23 \quad\Rightarrow\quad \boxed{c_1=2.3}. \]

Substitute into \(4c_0+6c_1=13\):

\[ 4c_0+6(2.3)=13 \] \[ 4c_0=-0.8 \quad\Rightarrow\quad \boxed{c_0=-0.2}. \]
Best-fit line: \[ \boxed{\hat y=2.3x-0.2} \]

2.5 Matrix / normal-equation form

The same least-squares problem can be written as

\[ A\mathbf c\approx \mathbf b, \] \[ A= \begin{bmatrix} 1&0\\ 1&1\\ 1&2\\ 1&3 \end{bmatrix},\qquad \mathbf c= \begin{bmatrix} c_0\\c_1 \end{bmatrix},\qquad \mathbf b= \begin{bmatrix} 0.5\\1.5\\3.5\\7.5 \end{bmatrix}. \]

The least-squares solution satisfies

\[ \boxed{\mathbf c=(A^TA)^{-1}A^T\mathbf b}. \]

First calculate

\[ A^TA= \begin{bmatrix} 4&6\\ 6&14 \end{bmatrix}, \qquad A^T\mathbf b= \begin{bmatrix} 13\\31 \end{bmatrix}. \]

The inverse is

\[ (A^TA)^{-1} =\frac{1}{20} \begin{bmatrix} 14&-6\\ -6&4 \end{bmatrix}. \]

Therefore

\[ \begin{aligned} \mathbf c &=\frac{1}{20} \begin{bmatrix} 14&-6\\ -6&4 \end{bmatrix} \begin{bmatrix} 13\\31 \end{bmatrix}\\[4pt] &=\frac{1}{20} \begin{bmatrix} -4\\46 \end{bmatrix} = \begin{bmatrix} -0.2\\2.3 \end{bmatrix}. \end{aligned} \]
The calculus solution and matrix solution are the same least-squares method written in two different forms. The matrix normal equations are exactly the equations obtained by setting the partial derivatives of the SSE to zero.

3. Fit a Parabola

Use the quadratic model

\[ \hat y(x)=c_0+c_1x+c_2x^2. \]

3.1 Write the four errors

\[ \begin{aligned} e_1 &= c_0-0.5,\\ e_2 &= c_0+c_1+c_2-1.5,\\ e_3 &= c_0+2c_1+4c_2-3.5,\\ e_4 &= c_0+3c_1+9c_2-7.5. \end{aligned} \]

3.2 Build the least-squares loss

\[ \begin{aligned} \rho(c_0,c_1,c_2)=&\,(c_0-0.5)^2\\ &+(c_0+c_1+c_2-1.5)^2\\ &+(c_0+2c_1+4c_2-3.5)^2\\ &+(c_0+3c_1+9c_2-7.5)^2. \end{aligned} \]

Expanding and collecting like terms gives

\[ \boxed{ \begin{aligned} \rho=&\,4c_0^2+12c_0c_1+28c_0c_2-26c_0\\ &+14c_1^2+72c_1c_2-62c_1\\ &+98c_2^2-166c_2+71. \end{aligned}} \]

3.3 Differentiate with respect to all three parameters

\[ \frac{\partial \rho}{\partial c_0} =8c_0+12c_1+28c_2-26 \] \[ \frac{\partial \rho}{\partial c_1} =12c_0+28c_1+72c_2-62 \] \[ \frac{\partial \rho}{\partial c_2} =28c_0+72c_1+196c_2-166. \]

Set all three equal to zero and divide by 2:

\[ \boxed{4c_0+6c_1+14c_2=13} \] \[ \boxed{6c_0+14c_1+36c_2=31} \] \[ \boxed{14c_0+36c_1+98c_2=83}. \]

3.4 Solve the system

Solving these three simultaneous equations gives

\[ \boxed{c_0=0.55},\qquad \boxed{c_1=0.05},\qquad \boxed{c_2=0.75}. \]
Best-fit parabola: \[ \boxed{\hat y=0.75x^2+0.05x+0.55} \]

3.5 Matrix / normal-equation form

\[ A= \begin{bmatrix} 1&0&0\\ 1&1&1\\ 1&2&4\\ 1&3&9 \end{bmatrix},\qquad \mathbf c= \begin{bmatrix} c_0\\c_1\\c_2 \end{bmatrix},\qquad \mathbf b= \begin{bmatrix} 0.5\\1.5\\3.5\\7.5 \end{bmatrix}. \]

Again, use

\[ \boxed{\mathbf c=(A^TA)^{-1}A^T\mathbf b}. \]

Calculate

\[ A^TA= \begin{bmatrix} 4&6&14\\ 6&14&36\\ 14&36&98 \end{bmatrix}, \qquad A^T\mathbf b= \begin{bmatrix} 13\\31\\83 \end{bmatrix}. \]

The inverse is

\[ (A^TA)^{-1}= \begin{bmatrix} \frac{19}{20}&-\frac{21}{20}&\frac14\\ -\frac{21}{20}&\frac{49}{20}&-\frac34\\ \frac14&-\frac34&\frac14 \end{bmatrix}. \]

Therefore

\[ \begin{aligned} \mathbf c &= \begin{bmatrix} \frac{19}{20}&-\frac{21}{20}&\frac14\\ -\frac{21}{20}&\frac{49}{20}&-\frac34\\ \frac14&-\frac34&\frac14 \end{bmatrix} \begin{bmatrix} 13\\31\\83 \end{bmatrix}\\[6pt] &= \begin{bmatrix} 0.55\\0.05\\0.75 \end{bmatrix}. \end{aligned} \]

5. Coordinate-Wise Newton-Raphson

The numerical routine begins with every coefficient equal to zero. During each complete sweep it updates one coefficient while holding the others at their latest values, then moves to the next coefficient. This is the alternating parameter optimization requested in the assignment.

\[ \frac{\partial \rho}{\partial c_j} =2A_j^T(A\mathbf c-\mathbf y), \qquad \frac{\partial^2 \rho}{\partial c_j^2}=2A_j^TA_j \] \[ \boxed{ c_j^{\mathrm{new}} =c_j^{\mathrm{old}} -\frac{\partial\rho/\partial c_j} {\partial^2\rho/\partial c_j^2}} \]

A sweep stops when the largest coefficient change is below \(10^{-10}\). The complete implementation is available in part2_newton.py; complete iteration data are available as CSV files below.

6. Key Relationship

The derivative and matrix approaches are equivalent:

\[ \nabla \rho(\mathbf c)=0 \quad\Longleftrightarrow\quad A^TA\mathbf c=A^T\mathbf b \quad\Longleftrightarrow\quad \mathbf c=(A^TA)^{-1}A^T\mathbf b, \]

The last expression assumes \(A^TA\) is invertible.
